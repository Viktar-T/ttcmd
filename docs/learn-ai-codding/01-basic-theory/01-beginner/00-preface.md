# Preface to the Beginner level

**Source (RU):** Предисловие к уровню «Новичок»  
**Path:** Home → Basic Theory → Level “Beginner”

Let’s start with the basics. You’ve probably heard terms like GPT, diffusion, or transformers — but what do they actually mean? In this chapter we’ll break down the key concepts of generative AI in simple, clear language. Step by step, we’ll put together a full picture of what is really going on inside these powerful systems.

The world of generative AI is moving at an incredible pace. Just a few years ago, the idea that a machine could write articles, create realistic images, or even generate code felt like science fiction. Today it is a reality that is changing how we work, learn, and create.

In this course we’ll get to grips with the basic principles behind modern generative models. You’ll learn how different types of models work, what tasks they solve, and how to use them properly. Don’t worry if a lot of it still feels unclear — we’ll start from the very basics and gradually move on to more complex topics.
