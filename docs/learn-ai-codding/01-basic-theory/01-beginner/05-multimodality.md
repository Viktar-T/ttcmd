# Multimodality

**Source (RU):** Мультимодальность  
**Path:** Home → Basic Theory → Level “Beginner” → Multimodality  
**Published:** ~4 weeks ago

Modern AI is becoming **multimodal** — it can work with more than one type of input, and it can generate more than one type of output.

A multimodal model can read text, natively “see” images, “hear” speech, “watch” video, and reply with text, an image, sound, and so on. These models convert inputs of different types (different **modalities**) into a single internal representation (**latent representation**), which lets the model understand them together. For example, the word “pencil” written as text, spoken aloud, or shown in a photo — for a multimodal model these are closely related things: vectors that sit near each other in **latent space**.

Examples of modern multimodal models include GPT-5.6, Gemini 3, Claude 5, Qwen3, and others.
