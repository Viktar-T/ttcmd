# Classification by data type

**Source (RU):** Классификация по типу данных  
**Path:** Home → Basic Theory → Level “Beginner” → Classification by data type  
**Published:** ~10 months ago

As you go deeper into AI, you will see abbreviations such as STT, TTS, or TTI. They simply describe what type of data the model takes in and what it produces:

- **STT:** Speech to Text
- **TTS:** Text to Speech
- **TTI:** Text to Image
- **ITT:** Image to Text
- **TTV:** Text to Video

…and so on.

Each code shows the direction of the transformation. Knowing these codes helps you quickly understand what a model can do.

For example, classic older models such as GPT-3.5 or LLaMA 2 can be classified as **text-to-text (TTT)**: the model takes text in and generates text out. An example of a speech-to-text model is OpenAI’s **Whisper**, built to transcribe spoken language into written text.

Other abbreviations include TTS (text-to-speech), TTI (text-to-image), ITV (image-to-video), TT3D (text-to-3D), TTV (text-to-video), and more.
