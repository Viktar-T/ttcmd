# Preface to the User level

**Source (RU):** Предисловие к уровню «Пользователь»  
**Path:** Home → Basic Theory → Level “User”

Congratulations! The basics are behind you 😊

Now it is time to roll up your sleeves and learn how to actually work with large language models — the same ones used in tools like ChatGPT, Claude, Gemini, and other services.

In this chapter we will cover terminology that will help you use LLMs more effectively. We will look at how prompts work, what tokens are, and how models handle memory. These ideas will help you write better instructions, understand model behavior, and avoid typical mistakes.
