To move from experimental prototypes to scalable AI products, you need specialized frameworks and tools that simplify application design, data flows, and talking to language models.

## Frameworks and libraries

**LangChain** — a framework for building LLM applications, focused on integrating models, tools, and memory into orchestrated call chains. Supports RAG, vector search, and agentic workflows. Available in Python and JavaScript.

**LangGraph** — a library on top of LangChain that lets you model LLM processes as graphs with state and asynchronous steps. Useful for building agent systems with complex logic.

**LlamaIndex** (formerly GPT Index) — a library that makes it easier to connect an LLM to your data. It provides a convenient interface for integrating with vector databases and documents, retrieval-oriented chains, and various indexing and search modes.

## Tools

**Dify** — an open-source platform for building LLM applications. Supports workflows, chat UIs, agents, and logs — without needing deep backend knowledge.

**n8n** — a visual workflow-automation tool that can connect LLM APIs to dozens of data sources, services, and databases. Ideal for no-code / low-code AI workflows.
