Hello, and welcome to **Basics of Programming with AI**.

If you have already taken other courses from our community — good to see you again. If this is your first course, welcome to the journey.

This course shows how programming changes when AI becomes part of the workflow. From the very first step — **prompt engineering** — through smart code suggestions, next-tab editing, AI chats inside the IDE, agentic code generation, **Model Context Protocol**, and other approaches that are now firmly rooted in AI-assisted development.

To get the most from the course, I recommend taking **[Basic Theory](../01-basic-theory/README.md)** first. It covers the key terms you need in order to understand the main principles of working with AI.

So stock up on tea or coffee, and let’s take the next step into programming with AI — together.
